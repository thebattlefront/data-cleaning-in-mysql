# Data Cleaning in MySQL

A SQL project focused on cleaning and preparing an imported dataset for further analysis using MySQL.

## Overview

Performed data cleaning operations to improve dataset consistency, address data quality issues, and prepare the data for analysis.

## Development Context

**Guided Learning Project**

Completed while following instructional material focused on SQL and data cleaning. The project provided hands-on practice identifying common data quality issues and applying SQL queries to prepare a dataset for further analysis.

## Features

- Identified and removed duplicate records
- Standardized inconsistent data values
- Handled NULL and blank values
- Removed unnecessary columns and rows
- Improved overall dataset consistency
